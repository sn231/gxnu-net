# 发布前隐私检查

检查日期：2026-10-27。

## 原始发布包的发现

原始 ZIP 外层只有 exe、配置模板、说明和两份自启脚本，没有真实 `config.ini` 或日志。然而 PyInstaller exe 内嵌 README 及客户端代码示例含有与本机配置一致的真实学号，README 还含本地开发目录。分发 exe 会一起分发这些内容。

对 exe 的 PyInstaller 归档及解压后的模块数据进行检查，未检出本机配置中已知密码的明文、URL 编码或 UTF-16LE 形式。该结论属于限定范围的静态检查，不能证明任意未知秘密或任意编码形式都不存在。

源码测试数据也含有真实账号密码，因此不能直接把原始源码目录提交到 Git。

## 公开版本的处理

- 从源码和启动、构建脚本白名单建立新目录，不带原目录历史和运行数据。
- 将与本机配置一致的真实学号及密码替换为虚构测试数据。
- 重写 README，删除本地路径，补充设计说明，并纠正凭据不会上传任何地方的说法：认证必须发送给校园网门户。
- 排除真实配置、日志、原始 ZIP、exe、备份及打包目录。
- 使用 GitHub noreply 地址提交，避免发布本机 Git 邮箱。

仓库内测试账号和 `ExamplePwd!.` 为虚构示例；`0MKKey`、PID 和 CALG 是协议常量。

公开版本与原始 exe 并非相同的字节产物。需要分发程序时，应从公开版本重新构建并检查产物，不要继续分发原始 ZIP。
